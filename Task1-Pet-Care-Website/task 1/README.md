# 🐾 Pet Care Website UI/UX Design

## 📌 Project Description

The **Pet Care Website** is a modern and user-friendly web interface designed in **Figma** for pet owners. The project focuses on creating a clean, visually appealing, and responsive experience that allows users to explore pet care services, learn about pet health, and easily connect with professionals.

This project was created as part of my **CodeAlpha UI/UX Design Internship**, following the complete UI/UX design process from wireframing to high-fidelity design.

## 🎯 Objectives

- Design a clean and modern Pet Care website.
- Create an intuitive and user-friendly interface.
- Improve navigation and overall user experience.
- Apply responsive design principles.
- Use Figma components and Auto Layout effectively.

## 🛠️ Tools Used

- Figma
- Auto Layout
- Components
- Variants
- Interactive Prototyping

## ✨ Features

- Responsive Landing Page
- Hero Section
- Pet Care Services
- About Us
- Testimonials
- Contact Section
- Modern UI Design
