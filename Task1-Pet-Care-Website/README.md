 🐾 Pet Care Website UI/UX Design

 📌 Project Overview

Pet Care Website is a modern and user-friendly interface designed in Figma for pet owners. The goal was to create a clean, attractive, and responsive website that allows users to explore pet care services with ease.

This project was completed as part of my **CodeAlpha UI/UX Design Internship**.

 🎯 Objectives

- Design a clean landing page
- Improve user experience
- Maintain proper visual hierarchy
- Create a responsive layout
- Use modern UI principles


🛠 Tool Used

- Figma

---

✨ Features

- Landing Page
- Hero Banner
- About Section
- Services
- Testimonials
- Contact Section
- Footer
